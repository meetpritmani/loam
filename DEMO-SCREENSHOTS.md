# Demo screenshots — listing assets

Log of screenshots captured for the Theme Store / marketplace listing and
demo store proof. Add a row per image as you capture it — file name, the
page it's from, and the screen size it was taken at. Nothing here is
auto-generated; this is the manual index.

Suggested naming: `loam-{page}-{size}.png` (e.g. `loam-home-desktop.png`,
`loam-product-mobile.png`) so a listing folder sorts sensibly without this
file — not enforced, just a default if you don't already have one.
